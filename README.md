# 🎵 Jazzify

Jazzify — это веб-приложение для потокового воспроизведения музыки, разработанное как клиент-серверный музыкальный сервис.

Приложение предоставляет возможность регистрации пользователей, авторизации, поиска и прослушивания музыкальных композиций, просмотра альбомов и исполнителей, а также управления пользовательской медиатекой.

---

# Основной функционал

* Регистрация пользователей
* Авторизация
* Потоковое воспроизведение музыки
* Поиск музыкальных композиций
* Просмотр исполнителей и альбомов
* Управление плейлистами
* Добавление композиций в избранное
* Пользовательская медиатека
* Мессенджер
* Пользовательские комментарии

# Требования

Перед запуском проекта убедитесь, что установлены:

* Laragon
* PHP **8.3 или выше**
* Composer
* Node.js и npm
* PostgreSQL

Для запуска серверной части используется **Apache**, входящий в состав Laragon.

---

# Установка проекта

## 1. Клонирование репозитория

```bash
git clone https://github.com/MarBikmur/Jazzify.git
```

Или скачайте архив проекта и разместите его в папке:

```
Laragon/www/
```

---

# Настройка Backend (Laravel)

Перейдите в директорию backend:

```bash
cd backend
```

Установите зависимости:

```bash
composer install
```

Создайте файл окружения:

```bash
.env
```

# Настройка базы данных

Создайте базу данных PostgreSQL.

Откройте файл:

```
.env
```

и укажите параметры подключения:

```env
DB_CONNECTION=pgsql
DB_HOST=127.0.0.1
DB_PORT=5432
DB_DATABASE=jazzify
DB_USERNAME=your_username
DB_PASSWORD=your_password
```

После настройки подключения выполните миграции:

```bash
php artisan migrate
```

---

# Настройка Frontend (Nuxt)

Перейдите в директорию frontend:

```bash
cd frontend
```

Установите зависимости:

```bash
npm install
```

Для запуска в режиме разработки:

```bash
npm run dev
```

Для создания production-сборки:

```bash
npm run build
```

---

# Запуск проекта через Laragon

1. Поместите проект в папку:

```
Laragon/www/
```

2. Откройте Laragon.

3. Запустите необходимые сервисы.

4. Убедитесь, что Apache выбран в качестве веб-сервера.

5. После запуска серверная часть Laravel будет доступна через локальный домен Laragon.
